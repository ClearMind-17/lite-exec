# Lite Exec 0.1.2 与 DSH 0.2.2-rc.5

2026-11-22，Windows。使用本机 `0.2.2-rc.5` 的 Electron 后端、隔离 Desktop profile 与模拟模型。测试脚本从实际宿主包读取版本。升级以日常安装包为基线，保留其工作区落盘和诊断行为。

`rc.5` 启动时核验组合包的 `engines.dsh`。原声明只匹配 `rc.3`，启用配置存在时也不会载入，四个工具请求均返回 `UNKNOWN_TOOL`。0.1.2 声明兼容 `rc.3` 和 `rc.5`。

| 项目 | 结果 |
| --- | --- |
| 组合包生命周期 | 基线、关闭、开启、移除四种状态符合预期。标准会话和 Flash PTC 可见四个 Lite 工具，既有工具集对照通过。 |
| Shell、文件与超时 | 20 次 PowerShell 调用和 1 次 Flash PTC 调用成功。5 项文件检查通过，覆盖普通路径和真实 ASAR。超时后确认测试子进程已退出。 |
| 只读 | 工作区内外写入均被拒绝。截断输出保留预览，grep 完整扫描 5,000 行匹配。两者均返回 `READ_ONLY` 落盘原因。 |
| 工作区写入 | 工作区外写入被拒绝。Codex 嵌套沙箱中，Lite 与原生 `pwsh` 均回落到 PowerShell 安装目录，并出现相同的工作区读取、写入失败。目录 ACL 拒绝物理落盘，Lite 保留预览并报告 `ACL_DENIED`。 |
| Memo 个人版 3.3.20 | 同开用例 8/8 通过。 |

隔离运行的 Shell 测试回归指标中，工作区内读写和物理落盘仍待普通 Windows 桌面会话验证。独立冒烟脚本在此环境中遇到 Git Bash 的 MSYS 初始化拒绝。指定 PowerShell 后，独立脚本的 `taskkill` 清理断言也未通过，实际 DSH 宿主的超时清理用例通过。
